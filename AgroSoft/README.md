# AgroSoft - The Google + Uber of Agriculture

🌾 **AgroSoft** is a comprehensive cross-platform mobile app that revolutionizes agriculture with AI, IoT, and FinTech integration. It provides farmers with modern tools for crop management, service booking, financial services, and marketplace access.

## 🚀 Features

### 🏠 Home Dashboard
- **Farmer Profile**: Complete profile with region, soil type, and primary crops
- **AI Crop Health Check**: Real-time crop health monitoring with disease risk assessment
- **Drone Imaging Integration**: Latest scan results with pest and disease detection
- **Quick Actions**: Easy access to all services with one-tap booking

### 🚜 Machinery Booking (Uber-style)
- **Multiple Categories**: Tractors, JCBs, Harvesters, Borewell Rigs
- **Dynamic Pricing**: Per hour/acre pricing with real-time availability
- **Live GPS Tracking**: Uber-style tracking with ETA and operator details
- **Rating System**: Rate operators and view ratings before booking

### 🧪 Soil Testing + AI Insights
- **Comprehensive Testing**: Basic, Advanced, and Comprehensive test packages
- **AI-Generated Reports**: pH, NPK, organic carbon analysis with recommendations
- **IoT Sensor Integration**: Live moisture, temperature, pH, and EC monitoring
- **Trend Analysis**: Historical data visualization and patterns
- **Crop Recommendations**: AI-powered crop suggestions based on soil health

### 🚁 Drone Services
- **Dual Services**: Spraying and Crop Health Imaging
- **AI Disease Detection**: Advanced imaging for pest and disease identification
- **NDVI Analysis**: Vegetation index analysis with precision agriculture
- **Real-time Reports**: Instant health reports with actionable insights
- **Chemical Options**: Multiple pesticide, fungicide, and fertilizer options

### 🛒 Marketplace
- **Crops & Dairy**: Direct farmer-to-buyer marketplace
- **Quality Ratings**: Grade A, Premium quality classifications
- **Location-based**: Local and regional product discovery
- **Direct Contact**: Seamless communication between farmers and buyers
- **Order Management**: Complete order tracking and management

### 👥 Worker Hiring
- **Multiple Categories**: Ploughing, Sowing, Harvesting, Weeding teams
- **Team-based Hiring**: Complete teams with experience ratings
- **Live Tracking**: Real-time worker location and ETA
- **Flexible Pricing**: Per day or per acre pricing options
- **Experience Verification**: Verified worker profiles with ratings

### 💳 AgroSoft Credit & Wallet
- **Yield-based Credit Scoring**: Credit limits based on historical yield data
- **Digital Wallet**: UPI, card, and net banking integration
- **Credit Applications**: AI-powered credit limit increases
- **Transaction History**: Complete financial tracking
- **Quick Payments**: Bill payments and money transfers

### 🗺️ Farm Mapping
- **Land Code System**: Unique AgroSoft ID for every farm plot
- **Satellite View**: High-resolution farm visualization
- **Plot Management**: Individual plot tracking with health status
- **Service Integration**: Direct service booking from map interface
- **Health Visualization**: Color-coded plot health indicators

### ⚙️ Settings & Personalization
- **Multi-language Support**: English, Telugu, Hindi, Tamil, Kannada
- **Farmer-friendly UI**: Large icons and intuitive navigation
- **Notification Management**: Customizable alerts and updates
- **Privacy Controls**: Comprehensive privacy and security settings

## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- Expo CLI
- Android Studio (for Android development)
- Xcode (for iOS development, macOS only)

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/agrosoft.git
   cd AgroSoft
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm start
   ```

4. **Run on device/simulator**
   ```bash
   # Android
   npm run android
   
   # iOS
   npm run ios
   
   # Web
   npm run web
   ```

### Building for Production

1. **Android APK**
   ```bash
   expo build:android
   ```

2. **iOS IPA**
   ```bash
   expo build:ios
   ```
